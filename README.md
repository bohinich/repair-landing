# US Appliance Repair Landing Page

Сучасний мінімалістичний темний лендінг для компанії з ремонту побутової техніки в США (холодильники, пральні машини, мікрохвильові печі, посудомийні машини).

## Особливості

- Темний преміальний дизайн
- Адаптивний під мобільні, планшети і десктопи
- Секція послуг (4 блоки)
- Форма запису з валідацією (Name, Phone, Problem)
- CTA-блоки
- Футер із контактами та соцмережами
- Плавні hover-ефекти
- Чистий HTML/CSS/JS (без React, без npm)

## Структура проекту

repair-landing-dark/
├─ index.html # Основна сторінка
├─ style.css # Стилі
├─ script.js # JS для валідації форми
└─ README.md # Інструкція

## Як запустити

1. Клонувати репозиторій або завантажити файли
2. Відкрити `index.html` у будь-якому браузері
3. Перевірити форму і секції лендінгу

> Для GitHub Pages:
>
> - Завантажте папку на GitHub
> - Активуйте GitHub Pages у налаштуваннях репозиторію
> - Виберіть гілку `main` / `root`
